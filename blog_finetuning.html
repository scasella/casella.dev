Withdrawn: ten mined examples and a 1.5B bug fixer

[ 2026-05-26 ] // Qwen2.5-1.5B-Instruct // WITHDRAWN 2026-09-23

I published this post on 2026-05-26 and withdrew it on 2026-09-23. It reported that a LoRA trained on ten mined fixes lifted Qwen2.5-1.5B-Instruct on a synthetic Python bug-repair benchmark, and that fixes mined with diagnostic test feedback carried over to unseen bug categories better than fixes mined with pass/fail feedback.

Why I withdrew it

Rechecking the run records turned up three problems that careful wording could not repair:

  • The test prompts named the bug category. Each test prompt carried the task ID and a "bug category hint". My own run notes flag the resulting scores as inflated by those hints.
  • The feedback comparison was not isolated. The two mining conditions used differently worded prompts. The diagnostic prompt mentioned two of the three held-out categories (mutation and type conversion). And its training set covered five bug categories against three for the pass/fail set. Any of these could explain the held-out gap of 3–4 against 0–1 of 6 programs.
  • The starting zero was mostly a format failure. 374 of the 384 baseline outputs contained no patch the harness could parse. So much of the lift from 0 came from learning the output format.

Separately, a later evaluation on real code, not yet published, achieved 1 successful repair out of 40. Without a matching baseline that shows low absolute performance, not an absence of transfer, so it is not one of the reasons above.
